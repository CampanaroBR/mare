# MARÉ

A concept product site for MARÉ, wireless over-ear headphones. It's a motion and interaction study.

**Live:** https://campanarobr.github.io/mare/

- Scroll-driven art direction: one scroll value choreographs photography, type and WebGL
- Exploded x-ray view of the headphones in three.js, with draggable rotation and callouts that reorder so their leaders never cross
- Noise-cancelling story told with a canvas wave field and procedural sound (Web Audio)
- Color switcher with a circular reveal from the swatch you press
- Plain HTML, CSS and JavaScript, with GSAP and Lenis. No build step.

Design and code by Arthur Fonseca, 2026. Product imagery was generated with AI and art-directed by the author. MARÉ is not a real product.
